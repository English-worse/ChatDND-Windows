# ChatDND v0.1.0

首个公开预览版本，提供 Windows 应用级免打扰功能。

## 主要功能

- 一键静音选中的聊天应用音频会话。
- 支持微信、QQ、钉钉等多开实例。
- 持续处理后来创建的音频会话。
- 只恢复由 ChatDND 修改过的静音状态。
- 中文托盘界面和首次应用识别。
- 可选管理员模式，带中文风险提示和 UAC。
- 异常退出后的恢复日志。

## 下载说明

- 下载 `ChatDND-v0.1.0-win-x64.zip`。
- 解压后运行 `ChatDND.exe`。
- 当前版本为 Windows 10/11 x64 自包含包，不需要额外安装 .NET。

## 已知限制

- 应用尚未创建音频会话时，极短的第一声提示音可能漏过。
- 免打扰会静音选中应用的全部音频，包括语音和视频。
- 受保护或独占模式音频可能无法由普通权限修改。
- 当前 EXE 尚未进行代码签名，Windows SmartScreen 可能提示未知发布者；请只从本仓库 Release 页面下载。

## 隐私

ChatDND 不联网，不读取聊天内容、联系人、剪贴板或键盘输入，不修改聊天软件内部设置。
